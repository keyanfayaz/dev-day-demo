# Homie · Raidio

An interactive conversation replay for a DevDay meetup talk: Homie, my Dot,
helps prepare Raidio's production setup across a MacBook Pro and Mac mini.

**[Open the presentation](https://keyanfayaz.github.io/dev-day-demo/)**

## Present

Open `index.html` in a browser. The replay and avatar are embedded in one file;
it needs no installation or internet connection. The final Raidio demo link
opens an external website.

- Click, or press Space, Enter, or Right arrow to advance.
- Press Left arrow to go back and F for full screen.
- Use **Replay** to start again.

## About the replay

This is an edited presentation using selected conversation excerpts. Some
transitions are reconstructed and the chapter dates follow the presentation
timeline. The messages show beta checks passing while production or TestFlight
release remained pending; they do not establish the app's current release status.

See the [presenter's guide](PRESENTING.md) for the exact sequence, benchmark
context, and reconstruction notes. All content and interactions live in `index.html`.
